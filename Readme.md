# Emmy And Laico

- Proyecto generado en Gdevelop
- Para los mapas se utilizó el programa tiled que permite generarlos de forma amigable con el usuario y exportar un archivo que es utilizable en gdevelop 

A modo de GDD el juego es un plataform clásico en donde el personaje principal (Emmy) busca a su perrito (Laico) para jugar con él.
Consta de varios tipos de plataformas: 
- Para el Terreno regular
- Plataformas moviles
- Plataformas débiles (que caen en cierta cantidad de tiempo)
- Plataformas Troll (el personaje no colisiona con ellas)
Por otro lado se implementó un sistema de enemigos que patrullan zonas especificas sin caer de los bordes que serán eliminados cuando Emmy salte sobre ellos o colisionen con ella (en este ultimo caso ambos son eliminados)

El jugador cuenta con 5 vidas para su aventura, en caso de perderlas todas este será redirigido a la ventana de muerte para comenzar desde el nivel 1.

Hasta el momento existen 3 NPC con los cuales Emmy puede interactuar y hablar con ellos:
1. Un cartel de instrucciones
2. Marisol una npc mujer
3. Fabian un npc hombre

Para interactuar y adelantar la conversa se puede pulsar el botón de acción ("e")

El fin de la aventura acaba cuando Emmy por fin puede encontrar a Laico... o bueno la foto de él.
